# C++ Sorting Algorithms

## Project Description

This project contains three sorting algorithms written in C++. These programs were created as part of my Computer Science coursework to practice implementing algorithms and understanding different ways to organize data.

## Algorithms Included

### Insertion Sort
Insertion sort works by comparing elements and moving them into their correct positions within the sorted portion of an array.

### Merge Sort
Merge sort uses recursion to divide an array into smaller sections. These sections are then merged back together in sorted order.

### Radix Sort
Radix sort organizes nonnegative integers by processing individual digits. It uses counting sort to arrange the numbers during each pass.

## Technologies Used
- C++
- Standard input and output
- Arrays
- Recursion
- Dynamic memory allocation

## How to Run

Each program can be compiled and run separately using a C++ compiler.

For example, to compile Merge Sort:

```bash
g++ Merge.cpp -o merge
```

Run the program:

```bash
./merge
```

Enter integers separated by spaces or new lines. When finished, signal the end of input (Ctrl+D on Linux/macOS or Ctrl+Z followed by Enter on Windows).

The program will display the numbers in ascending order.
